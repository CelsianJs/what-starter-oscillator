# Oscillator

Oscillator is a What Framework starter for a browser music studio. It includes a real Web Audio sixteen-step sequencer, tempo and swing controls, mute and solo, presets, local save, and JSON export.

## Quick start

```bash
npm ci
npx playwright install chromium
npm run dev
```

Open the local Vite URL and visit `/studio`. Click **Start audio** before expecting sound. Browsers require a user gesture before Web Audio can play.

## Scripts

```bash
npm run dev          # local Vite dev server
npm run build        # production build plus static route aliases
npm run preview      # serve the production build locally
npm test             # Vitest unit coverage
npm run smoke        # Playwright browser flow and screenshots
npm run deploy       # Vura preview deploy, requires auth
npm run deploy:prod  # Vura production deploy, requires auth
```

On minimal Linux CI images that do not already include browser system libraries, use `npx playwright install --with-deps chromium` before `npm run smoke`.

## What it demonstrates

- What signals and computed state for pattern editing in `src/state/studio.js`.
- Web Audio scheduling and cleanup in `src/audio/engine.js`.
- Accessible step buttons, sliders, mute and solo controls in `src/components/Sequencer.jsx`.
- Local persistence and JSON export from `src/components/PresetPanel.jsx`.
- Static Vura aliases generated by `scripts/generate-static-aliases.mjs`.

## Browser support

The starter requires Web Audio for playback. It does not request microphone access, record audio, upload audio, or call an external service.

## Deploy notes

Root deployment is expected to publish this as `CelsianJs/what-starter-oscillator` and deploy it with `vura-platform@0.3.0`.

Known static aliases are generated for `/studio`, `/build`, and `/404`.
